## Semantic Structure
- `header` contains the course name, page heading, and navigation.
- `nav` contains links to every page in the website.
- `main` contains the primary page content.
- `article` groups the page's main related content.
- `section` divides the article into individual topics.
- `aside` contains the W3C Warning related to Document Outlines.
- `footer` contains the CSUN link and address.
## ARIA Roles
The pages use `banner`, `navigation`, `main`, `complementary`, and `contentinfo` where appropriate.
